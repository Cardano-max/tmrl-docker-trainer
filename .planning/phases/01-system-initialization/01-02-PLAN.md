  ```python
  class SystemInitializer:
      """
      System initialization sequence (Sutton Jan 24, 2026).

      Sequence:
        1. Load config
        2. Validate config (INIT-01)
        3. Check prior knowledge (INIT-02, INIT-04)
        4. If no prior knowledge: run bin discovery (INIT-03)
        5. Print status at each stage (INIT-05)
        6. Frame duration from config (INIT-06)

      Sutton quotes:
        "the system won't start before it the experiments"
        "when there is previous knowledge... no need to validate anything"
        "you can print everything to screen like validation started, bins acquired"
      """

      def __init__(self, config_path: str = None, adapter=None):
          """
          Args:
              config_path: Path to JSON config file (default: config/tmnf_config.json)
              adapter: Pre-created environment adapter (TMNFAdapter or any adapter
                       with get_feedbacks() and send_action_dict()). If None,
                       the initializer will create one from config.
          """
  ```

  **Stages:**

  1. **_load_config(config_path)** -> Load and parse JSON. Print status. Return False if file not found or invalid JSON.

  2. **_validate_config()** -> Use ConfigValidator.validate_config(). Print "[+] Config validated: 3 actions, 1 feedback". Return False if validation raises. INIT-01. Also extract frame_duration_ms from config here (INIT-06) and store as `self.frame_duration_ms`.

  3. **_check_prior_knowledge()** -> Use PriorKnowledgeManager. If results exist, load them, store bins, return True. If not, return False. Print status either way. INIT-02.

  4. **_connect_adapter()** -> If adapter was passed in constructor, use it. If not, create TMNFAdapter from config (host, port). Connect with timeout. Print status. This is optional (offline mode skips this). Return the adapter or None.

  5. **_acquire_bins(adapter)** -> Create ExperimentationCoordinator or run equivalent of test_phase_a_tmnf.py flow. Use `wait_fn=adapter.wait_one_tick` (NOT `time.sleep` -- for TMNF, `time.sleep` desynchronizes from TMInterface TCP; the adapter's wait_one_tick sends the TCP "advance" command). Fall back to `wait_fn=time.sleep` ONLY if adapter lacks a `wait_one_tick` method (use `getattr(adapter, 'wait_one_tick', lambda: time.sleep(self.frame_duration_ms / 1000.0))`). Frame duration from self.frame_duration_ms. After discovery, save results via PriorKnowledgeManager.save_results(). Print status. INIT-03.

  6. **_report_ready()** -> Print final summary: bins per action, frame duration, source (prior/discovered). INIT-05.

  **The initialize() method:**

  ```python
  def initialize(self) -> InitializationResult:
      print("=" * 60)
      print("SYSTEM INITIALIZATION")
      print("  Sutton Jan 24: 'the system won't start before it the experiments'")
      print("=" * 60)

      # Stage 1: Load config
      if not self._load_config():
          return self._fail_result()

      # Stage 2: Validate config (INIT-01)
      if not self._validate_config():
          return self._fail_result()

      # Stage 3: Check prior knowledge (INIT-02, INIT-04)
      has_prior = self._check_prior_knowledge()

      if has_prior:
          # INIT-04: Load prior knowledge, skip experimentation
          self._print_status("Prior knowledge loaded", "ok", "Skipping experimentation")
      else:
          # INIT-03: Must acquire bins before proceeding
          adapter = self._connect_adapter()
          if adapter is None:
              self._print_status("Bin acquisition", "fail", "No adapter (game not running?)")
              return self._fail_result()
          if not self._acquire_bins(adapter):
              return self._fail_result()

      # Stage 4: System ready (INIT-05)
      self._report_ready()

      return InitializationResult(
          success=True,
          has_prior_knowledge=has_prior,
          bins_acquired=self.bins,
          frame_duration_ms=self.frame_duration_ms,
          stages=self.stages,
          errors=self.errors,
          warnings=self.warnings
      )
  ```

  **CRITICAL implementation notes:**
  - `self.frame_duration_ms` is ALWAYS read from config, NEVER hardcoded. Sutton Jan 24: "this needs to be determined by the system so it's being configured not hard-coded"

  - When prior knowledge exists, the system does NOT validate config (Sutton: "when there is previous knowledge... no need to validate anything") -- BUT we still load and parse config for frame_duration_ms. Only the action/feedback validation is skipped.
  - Actually, re-reading the transcript more carefully: "no need to validate anything because the previous knowledge knows everything" means we skip action/feedback validation AND experimentation. We still need the config for frame_duration_ms and adapter settings. So: load config always, validate ONLY if no prior knowledge, experiment ONLY if no prior knowledge.
  - Status messages must be printed (INIT-05). Use the existing _print_status pattern with symbols: [+] ok, [X] fail, [~] start, [o] skip.
