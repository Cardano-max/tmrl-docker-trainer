<decisions_made>

- **Switch to TMNF over TM2020**: TMNF has 10ms deterministic ticks (game pauses for Python input), save/rewind capability, full state access. Makes Sutton's algorithm work "200% pure" — no D0 subtraction needed, no noise epsilon, single tick per probe. TM2020 has 50ms non-deterministic ticks with timing jitter.
- **Per-probe D0 subtraction** (for TM2020 path): Instead of one D0 at start, each probe measures local physics first (frame 1: action=0) then action (frame 2), subtracts to isolate pure action signal. Removes inherited momentum/drag contamination.
- **Gas/brake from rest**: At speed=0, there's no drag, no inertia — Pong-like. Delta depends only on action value. No ensure_measurable_regime needed for gas/brake.
- **Steering still needs speed**: Heading measurement requires displacement, so ensure_measurable_regime runs only before steering.
- **Dual epsilon**: noise_epsilon (0.05 km/h) for measurement variance floor, signal_epsilon (1e-7) for game float precision. Steering uses smaller values (radians vs km/h).
</decisions_made>
